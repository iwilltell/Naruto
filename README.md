## 📖 About the Project

**Naruto** is a fan-made web development project inspired by the world of Naruto Uzumaki.

Built to bring the spirit of the Hidden Leaf Village to the web, this project explores frontend development while celebrating one of the most iconic anime universes.

## ⚡ Tech Stack

- HTML5
- CSS3
- JavaScript
- Vite

## 📁 Project Structure

```text
naruto/
├── public/          # Static assets
├── src/             # Application source code
├── .gitignore
├── index.html
├── package.json
├── package-lock.json
└── vite.config.js
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd naruto
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```
